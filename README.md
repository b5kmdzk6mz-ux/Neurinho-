# Neurinho

Neurinho: estudo que cabe no seu dia. App de estudo ativo para estudantes de Enfermagem.

## Jogo: A Jornada das Sinapses

Na tela Início, toque em **Jogar**. O Neurinho enfrenta cinco vilões (Procrastino, Distrax, Barão Insônia, Ansiax e Dona Bagunça) e o chefe final Lorde Apagão respondendo questões do banco de estudo. História, regras e vilões estão em [JOGO.md](JOGO.md).
